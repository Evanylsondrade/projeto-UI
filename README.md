
  # Pet Shop Management UI/UX

  This is a code bundle for Pet Shop Management UI/UX. The original project is available at https://www.figma.com/design/TsIGf4l3FI7CY8Xxwwqhsr/Pet-Shop-Management-UI-UX.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

## Backend SmartPet

A infraestrutura, o login real de funcionários e a gestão de tutores estão em `backend/`. Consulte [as instruções do backend](backend/README.md) para criar a primeira conta gerencial, iniciar os servidores e verificar os limites desta etapa.

Use `npm run server` para iniciar a API local e `npm run dev` em outro terminal para o frontend. Login e Tutores já usam o banco; as outras áreas permanecem demonstrações locais, sem importação automática. As antigas contas de exemplo não são mais aceitas. Use `npm run test:backend` para testar o backend.
